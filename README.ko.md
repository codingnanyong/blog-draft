# Blog Draft

[한국어](README.ko.md) | **English**은 [README.en.md](README.en.md)를 참고하세요.

매주 1개의 기술 블로그 글을 준비하고, 사람이 검토한 뒤 Velog(한국어)와 Medium(영어)에 발행하기 위한 콘텐츠 저장소입니다.

## 저장소 역할

- **GitHub**: Markdown 초안과 AI 생성 이미지를 버전 관리합니다.
- **Google Drive**: 동일한 콘텐츠 산출물을 백업하고 검토·공유합니다.
- **Notion**: 프로젝트와 주간 Sprint를 관리합니다.
- **Linear**: 실제 실행 Issue를 관리합니다.
- **Slack**: 초안 준비, 동기화 및 실패 알림을 전달합니다.

## 운영 원칙

- 매주 1개의 초안을 준비합니다.
- AI가 생성한 내용과 이미지는 발행 전에 사람이 검토합니다.
- 한국어 원고는 Velog에, 영어 번역본은 Medium에 최종 발행하며, 둘 다 수동으로 진행합니다.
- 검토가 완료된 변경은 `feat/*` → `develop` → `main` 순서로 Pull Request를 통해 반영합니다.
- 진행 중인 시리즈는 여러 주차에 걸쳐 이어지며, [로드맵](docs/kor/ROADMAP.md)에서 전체 계획을 관리합니다.
