# Velog Draft

매주 1개의 Velog 기술 블로그 글을 준비하고, 사람이 검토한 뒤 발행하기 위한 자동화 프로젝트입니다.

## Workflow

1. Notion에서 프로젝트와 주간 Sprint를 관리합니다.
2. Linear에서 실행 Issue를 관리합니다.
3. 초안과 문서 산출물은 Google Drive에 보관합니다.
4. Codex와 Cursor로 자동화 코드를 구현합니다.
5. GitHub에서 코드, Pull Request, Release를 관리합니다.
6. Slack `#velog-automation`에서 실행 결과와 실패 알림을 확인합니다.

## Publishing policy

- 초안은 자동으로 생성합니다.
- 발행 전 사람이 내용을 검토합니다.
- Velog 발행은 수동으로 진행합니다.
