# Velog Draft

**English** | [한국어](README.ko.md)

A content repository for preparing one Velog technical blog post per week, reviewed by a human before publishing.

## Repository role

- **GitHub**: Version-controls the Markdown drafts and AI-generated images.
- **Google Drive**: Backs up the same content deliverables for review and sharing.
- **Notion**: Manages the project and its weekly sprints.
- **Linear**: Manages the actual execution issues.
- **Slack**: Delivers draft-preparation, sync, and failure notifications.

## Operating principles

- One draft is prepared per week.
- AI-generated content and images are always reviewed by a human before publishing.
- Publishing to Velog is done manually.
- Reviewed changes land through pull requests, in order: `feat/*` → `develop` → `main`.
- An ongoing series spans multiple weeks; the full plan lives in the [roadmap](docs/eng/ROADMAP.md).

See [Content & publishing workflow](docs/eng/WORKFLOW.md), [Repository structure & writing guide](docs/eng/PROJECT_STRUCTURE.md), [Git branch strategy](docs/eng/GIT_WORKFLOW.md), and [Roadmap / series plan](docs/eng/ROADMAP.md) for details.
