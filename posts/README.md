# Posts

글 하나당 하나의 폴더를 사용합니다. 언어별 버전(한국어 → Velog, 영어 → Medium)은 같은 폴더 안에서 파일만 나눕니다.

예시:

```text
posts/2026/09/my-first-post/
├── index.ko.md
├── index.en.md
└── images/
    ├── cover.webp
    └── diagram-01.webp
```

폴더명은 영문 소문자와 하이픈으로 작성하고, 이미지는 가능하면 WebP 형식을 사용합니다. `images/`는 언어 버전 간에 공유하므로 중복 저장하지 않습니다. Google Drive에도 같은 폴더 구조로 저장합니다.
