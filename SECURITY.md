# Security Policy

## 한국어

이 저장소는 정적 콘텐츠(Markdown, 이미지)만 포함하며 실행 가능한 애플리케이션 코드는 없습니다. 다만 저장소 내에서 노출된 민감 정보(API 키, 개인정보 등)를 발견하시면 공개 Issue 대신 codingnanyong@gmail.com 으로 비공개 제보 부탁드립니다.

## English

This repository contains only static content (Markdown and images) — there is no executable application code. If you discover exposed sensitive information (API keys, personal data, etc.) anywhere in this repo, please report it privately to codingnanyong@gmail.com rather than opening a public Issue.
