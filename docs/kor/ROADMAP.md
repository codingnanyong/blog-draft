# 로드맵 / 시리즈 계획

## "코딩 도감" 시리즈 개념

포켓몬 도감처럼, 매 시리즈(`#번호`)는 하나의 기술 "개체"를 다룹니다. 하나의 개체는 여러 주차에 걸쳐 기초부터 실전까지 단계적으로 학습하고, 마지막 주차에서 해당 개체를 "코딩 도감"에 정식 등록하는 형태로 마무리합니다.

## #01 — Git (5주 계획)

| 주차 | 주제 | Linear | 상태 |
| --- | --- | --- | --- |
| 1주차 | Git 기본 — 첫 조우 | COD-41 | 발행 완료 |
| 2주차 | Git의 Branch, Merge | COD-42 | 진행 예정 |
| 3주차 | 되돌리기 & Merge Conflict | COD-53 | 계획됨 |
| 4주차 | 원격 저장소 & Rebase | COD-54 | 계획됨 |
| 5주차 | 협업 워크플로우 (마무리) | COD-55 | 계획됨 |

각 주차는 [Git 브랜치 전략](GIT_WORKFLOW.md)과 [콘텐츠 & 발행 워크플로](WORKFLOW.md)에 정의된 동일한 프로세스를 따릅니다. 5주차가 끝나면 Git 개체는 도감에 정식 등록되고, 다음 개체(`#02`)를 위한 주제 선정이 시작됩니다.
